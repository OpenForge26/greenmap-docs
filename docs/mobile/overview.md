# App Patient — Vue d'ensemble

Application mobile React Native destinée aux patients. Permet de rechercher des médicaments, localiser les pharmacies et trouver les pharmacies de garde.

## Fonctionnalités

- Recherche de médicaments par nom
- Carte GPS des pharmacies proches
- Pharmacies de garde du jour
- Profil patient
