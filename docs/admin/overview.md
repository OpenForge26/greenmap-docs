# Admin Dashboard — Vue d'ensemble

Panel super admin Next.js 14. Accès réservé aux comptes avec le rôle `super_admin` dans la table `profiles`.

## Fonctionnalités

- Vue globale (KPIs toutes pharmacies)
- Gestion des pharmacies (valider, suspendre)
- Suivi des abonnements
- Planning de garde Togo & Bénin
- Gestion des utilisateurs

## Accès

Login sur `/login` → vérification du rôle `super_admin` avant redirection vers `/admin`.
