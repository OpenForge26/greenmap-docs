# Admin — Abonnements

Page `/admin/subscriptions` — suivi des abonnements pharmaciens.

## Statuts

| Statut | Description |
|---|---|
| `active` | Abonnement en cours |
| `pending` | En attente de paiement |
| `expired` | Expiré |
| `cancelled` | Annulé |

## Tarif

**12 500 FCFA / mois** par pharmacie.

## Paiements

Via CinetPay / Klasha — Mobile Money Togo & Bénin.
