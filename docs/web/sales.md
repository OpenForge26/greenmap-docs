# App Pharmacien — Ventes

Page `/dashboard/sales` — enregistrement des ventes et historique.

## Fonctionnalités

- Nouvelle vente (sélection produits, quantité, mode de paiement)
- Paiement Mobile Money (Flooz, Mixx, MTN, Moov)
- Historique des ventes
- Reçu client

## Tables Supabase

- `sales` — entête de vente
- `sale_items` — lignes produits
- `sale_payments` — détail du paiement
