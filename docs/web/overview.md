# App Pharmacien — Vue d'ensemble

Dashboard web Next.js 14 destiné aux pharmaciens abonnés. Permet de gérer le stock, les ventes, les patients et les statistiques.

## Fonctionnalités

- Dashboard avec KPIs en temps réel
- Gestion du catalogue médicaments
- Caisse et historique des ventes
- Carnet patients
- Statistiques et alertes stock
